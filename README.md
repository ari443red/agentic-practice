## Notes

This repository is a scratch space for experimenting with agent-assisted workflows. Nothing here is production code, and the file names are deliberately generic so that the focus stays on the process rather than the artifacts. Treat every file as disposable and feel free to delete or rename them without ceremony.

The most useful habit when working this way is to keep the feedback loop tight. Make one small change, run the check that catches mistakes, and only then decide what to do next. Batching a dozen speculative edits and running them all at once makes it much harder to tell which one actually helped.

Reading before writing matters more than it seems. A quick pass over the existing structure usually reveals conventions that a new file should follow, and occasionally reveals that the change you are about to make is already implemented somewhere you did not look. Skipping that step tends to produce duplicate work that is annoying to clean up later.

When something fails, resist the urge to rewrite the whole thing. Isolate the smallest failing case, read the actual error rather than a summary of it, and form one hypothesis at a time. Most bugs are boring once you are looking at the right line, and the ones that are not usually turn out to be a misunderstanding about the interface somewhere upstream.

Finally, write down what surprised you. Short notes about the tools that worked well, the ones that did not, and the approaches that turned out to be dead ends are worth far more later than they feel like at the time. That record is what turns a pile of experiments into something you can actually learn from.
